# Parent Structure — Moltwork × StallShark × MythicBee

**Date:** 5 September 2026

---

## The Three-Company Split

```
                     MOLTWORK
          infrastructure for autonomous work
                       │
                       ▼
                  STALLSHARK
        autonomous marketplace commerce
                       │
                       ▼
                   MYTHICBEE
       actual consumer business / laboratory
```

Three different abstraction levels. Each owns different things.

---

## 1. Moltwork.com — Foundational Layer

> **Moltwork: infrastructure for autonomous agents to work.**

### Moltwork Owns

```
WORK
├── jobs / opportunities
├── workers / capabilities / tools
├── budgets / permissions
├── execution / verification
├── proofs / receipts / payments
├── reputation / memory / learning
└── worker-to-worker procurement

RESEARCH
├── WorkerKit / Oracle / Repute
├── Arenav2 / mwgym
├── economic trajectories
├── operator models / model routing
├── capability marketplace
└── capital allocation
```

The atomic Moltwork object:

```
JOB → world state → opportunity → worker → resources → action → artifact → verification → outcome → reward → learning
```

Works for: ecommerce, software, security, research, Bittensor, forecasting, content, lead gen, physical-world jobs.

**One-line scope: Moltwork is infrastructure for autonomous agents to work.**

---

## 2. StallShark.com — Commerce Intelligence

> **StallShark: intelligence and autonomous tooling for marketplace sellers.**

### StallShark Owns

```
DATA: marketplace history, sold prices, competition, search demand, trends
RESEARCH: niches, competitors, product opportunities, pricing, supply/demand
EXECUTION: Etsy/eBay/Amazon/TikTok/Shopify adapters, listings, ads, inventory
PRODUCT: Radar, Spy, Trends, Lab, Operator
```

The loop:

```
SEE MARKET → FIND OPPORTUNITY → CHOOSE MARKETPLACE → CHOOSE PRODUCT
→ BUILD / SOURCE → LIST → PROMOTE → SELL → MEASURE PROFIT → IMPROVE
```

**One-line scope: StallShark is intelligence and autonomous tooling for marketplace sellers.**

StallShark becomes a feature within StallShark (competitor intelligence).

---

## 3. MythicBee.com — Consumer Business

> **Turn your dog into the star of a personalized movie, story or gift.**

Think: JibJab × Moonpig × AI video × pets.

### MythicBee Owns

```
dog upload → pet identity → character consistency
→ personalized scenes → cinematic templates
→ animation → greeting experiences → gift flows
→ cards / prints / mugs / POD → viral sharing
```

Does NOT own: Arenav2, Oracle, mwgym, eBay research, capital allocation, agent reputation, worker protocols.

## The Relationship

```
MOLTWORK → powers → STALLSHARK → operates/learns from → MYTHICBEE
```

StallShark doesn't have to operate only MythicBee:

```
                    STALLSHARK
        ┌──────────────┼──────────────┐
        ▼              ▼              ▼
    MythicBee       Brand #2        Brand #3
     Etsy          eBay arb      Amazon brand
      POD          resale         inventory
```

**MythicBee is one company. StallShark learns how to build companies. Moltwork learns how to build workers.**

## Scope Boundary (Frozen)

- MythicBee: actual consumer business / laboratory
- StallShark: intelligence and autonomous tooling for marketplace sellers
- Moltwork: infrastructure for autonomous agents to work

Each level uses the one below it. Each level learns from the one above it.
