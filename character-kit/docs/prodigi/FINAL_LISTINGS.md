# Final validation listings — occasions + £1.99 clip add-ons

Pricing logic (from MARKET_RESEARCH.md): under-$10 converts fast with 5–10 reviews (loss-leader zone),
$15–35 is the core sweet spot, bundles need 15–30 reviews. £1.99 clip math: ~£0.60 Etsy fees +
~£0.20 generation = ~£1.20 margin. It buys reviews and traffic, not profit.

## £1.99 fifteen-second clip menu (add-ons, attach to anything)

Ship these eight, no more until 20 orders each:
1. Standup set about X ("watch your dog do standup about Dave")
2. Roast of the owner/recipient
3. Breaking-news birthday bulletin
4. Confession cam ("I ate the socks")
5. Acceptance speech (tiny trophy energy)
6. Birthday-song fail (forgets the words)
7. Sports commentary (Dad scores / walk-off)
8. Bedtime grumble (anti-lullaby)

Each: pet photo in, captioned 15-sec MP4 out, share URL included (viral loop per MOGMUG_DEV_PLAN).

## Listing hygiene (100-shop study)

130+ char titles, all 13 tags, flatlay/3D mockups, shop-wide ~25% sale live from day one,
sub-£5 variant visible in search where allowed. One niche per shop: pet-owner gifts only.

## Validation rule (kill criteria)

- 30 days or 20 orders per listing, whichever first.
- Kill: <2% view-to-order with 200+ views. Fix first: thumbnail, title, price.
- Scale: winners get occasion-art variants (Halloween/Xmas) + portal upsell (mug/card).
- Memorial/breed packs only after one core winner converts.
