# Prodigi × Etsy integration (alternative path)

Prodigi offers native Etsy auto-fulfilment: connect the shop in dashboard Sales channels,
toggle products on, map artwork (or leave blank to personalise per order), and Etsy orders
route to the print network with tracking pushed back. Free image library, mockup generator,
sample packs (50% off first sample order), white-label packaging.

When to use it vs our API path: the integration is fastest for standard personalised
products; our API path (this kit's builder) is required wherever the asset is generated
per order (pet portrait → print art) or the trigger resolver must be embedded.
Both can coexist: integration for static designs, API for MogMug portals.

Guide: dashboard Etsy fulfilment PDF + /faq/etsy/.
