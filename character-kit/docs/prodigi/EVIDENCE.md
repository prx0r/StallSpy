# Evidence grades for THE TEN — no random picks

Two sources, graded per pick. Repo: `research/archive/MARKET_RESEARCH.md` (Sept 2026, Etsy pet niche:
250K+ monthly searches, portraits top-10 3yrs, PawtraitDesignCo 44.7K sales one listing, sweet spot
$15–35, video+card gap = nobody bundles). External: Trendlytic/StarterX/mydesigns/Merchize/WestCoastCraft 2026
roundups + Prodigi's own collection pages. Caveat (Trendlytic, honest): Etsy publishes no official
ranking; categories are durable, individual winners rotate — verify with eRank/EverBee before scaling.

## Tier A — both sources agree

- **Photo mug**: "custom mug" top-volume Etsy search; pet-portrait-mug angle everywhere; repo sweet spot.
- **Ornament + bauble**: Q4 single biggest revenue period for sublimation shops; pet ornaments "evergreen
  seasonal"; photo+name simplest winner; memorial/rainbow-bridge angle huge (see below).
- **Cards (both)**: repo's core gap (video+card bundle nobody sells); greetings = deadline-driven gift intent.
- **Cushion**: custom pet pillows/blankets = high order value + gift intent, both sources.
- **Stickers**: high-volume impulse + bundle item, both sources.
- **Print**: wall art durable; memorial posters angle; sets sell.

## Tier B — single-source or hunch, keep but watch

- **Magic mug**: novelty/reveal is our differentiation thesis, NOT a bestseller-list item. Keep as upsell,
  demote if plain-mug conversion beats it 3:1 after 20 orders.
- **Bandana**: Prodigi pushes it + pet apparel converts, but repo research doesn't rank it. Breed-specific
  angles ("Corgi dad") are the unlock per external; generic bandana will drown.

## Angles the evidence demands (not new SKUs)

- **Memorial / rainbow bridge**: strongest emotion in the category (portraits, ornaments, blankets all cite it).
  Add a memorial art pack + copy variant before Q4. Sensitive — human review every memorial order.
- **Breed-specific**: "wide open" per external; generic pet aisle is crowded. Art packs per breed, not new products.
- **Niche down**: one focused shop (pet-owner gifts) outranks generalist. Our Ten already does this.

## Next two after validation (not now)
