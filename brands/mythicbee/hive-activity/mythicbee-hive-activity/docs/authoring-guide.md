# Phrase authoring guide

## The voice

A strong HiveActivity line is:

- short enough to understand in one glance
- active
- slightly strange
- concrete
- not marketing copy
- not a promise
- occasionally mundane

The mundane lines are essential. Without them, whimsical lines stop being funny.

Good mixture:

```txt
Taking notes…
Consulting the hive…
Recombobulating…
Asking Gerald for some reason…
Checking what can actually arrive…
```

Bad mixture:

```txt
Buzzifying…
Bee-lieving…
Bee-autifying…
Bee-witching…
Bee-spoke-ing…
```

That becomes exhausting immediately.

## Recommended distribution

Across a large bank:

- 45% useful / grounded
- 20% dry character
- 15% Hive fiction
- 10% context-aware
- 7% nonsense
- 3% rare/easter-egg

Seasonal packs should modify/add only roughly 15–25% of visible lines during a session.

## Seasonal design principle

The season changes the Hive, not the underlying product truth.

Christmas examples:

```txt
Stinging the elves…
Checking Santa's fulfilment SLA…
Putting {hook} under the tree…
```

Halloween:

```txt
Stinging the trick-or-treaters…
Making this mildly cursed…
Consulting Lucifer, unfortunately…
```

Father's Day:

```txt
Rejecting another generic Dad mug…
Checking whether he still thinks he could've gone pro…
```

## Contextual safety

Use semantic hooks rather than raw transcript.

Good:

```txt
Reconsidering the Wembley incident…
```

Avoid:

```txt
Reconsidering Dad's cancer diagnosis…
```

The upstream hook generator should exclude sensitive categories from loader copy by default.

## Bee personality

Bee bias should be subtle.

Martin is not a different product. He simply causes value/practical lines to appear somewhat more frequently.

Lucifer increases chaotic/absurd phrasing but should still surface grounded status often enough that the UI remains useful.

## Rare lines

Rare phrases are an easter egg, not the baseline.

Examples:

```txt
Fluffernectaring…
Performing minor bee bureaucracy…
Rearranging the pollen alphabetically…
```

Set long cooldowns.

## Timing

Default phrase hold:
- 2.1–4.8 seconds

Longer:
- comprehension-heavy contextual lines
- reduced-motion mode

Shorter:
- visually obvious actions during animation

Do not switch on a metronome. Variability is part of the fluidity.
