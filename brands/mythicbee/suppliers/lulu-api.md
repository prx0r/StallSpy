# Lulu Print API Reference
**Source:** https://www.lulu.com/sell/sell-on-your-site/print-api
**Docs:** https://api.lulu.com/docs/
**Auth:** OAuth2

## Key Features
- Print books from PDFs (interior + cover)
- 3,000+ format configurations
- Global printing network (US, UK, EU, Australia, Canada)
- Personalized book-of-one printing
- Direct-to-customer shipping

## Products
- Hardcover books
- Softcover/paperback
- Photo books
- Children's books
- Comic books
- Magazines
- Notebooks
- Calendars
- Coil-bound books

## Workflow
1. Customer places order
2. Send print job to Lulu (PDFs + shipping info)
3. Lulu prints
4. Lulu ships to customer with tracking
